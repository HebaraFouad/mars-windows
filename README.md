# Mars

Fichiers d'installation de Mars. Le code n'est pas ici.

Télécharge la dernière version : **[Releases › Latest](https://github.com/HebaraFouad/mars-windows/releases/latest)**

| Fichier | Appareil | Installation |
| --- | --- | --- |
| `Mars-Setup-x.y.z.exe` | PC Windows | Ouvre le fichier. Si Windows affiche « Windows a protégé votre ordinateur », clique sur « Informations complémentaires », puis sur « Exécuter quand même ». Mars se met ensuite à jour tout seul. |
| `Mars-webOS-x.y.z.ipk` | Télé LG webOS | Avec Homebrew Channel ou `ares-install`. |
| `Mars-AndroidTV-x.y.z.apk` | Android TV, Google TV, box Android | `adb install -r Mars-AndroidTV-x.y.z.apk`, ou avec un gestionnaire de fichiers. |
